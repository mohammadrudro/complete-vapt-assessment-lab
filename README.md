# Complete VAPT Assessment Lab

## Project Overview
This repository documents a hands-on Vulnerability Assessment and Penetration Testing (VAPT) project conducted in a controlled lab environment.

The project focuses on practical security testing, reconnaissance, network scanning, service enumeration, vulnerability assessment, and exploitation of intentionally vulnerable systems.

## Lab Environment
- **Attacker Machine:** Kali Linux
- **Target Machine:** Metasploitable 2
- **Reconnaissance Target:** megacorpone.com (passive reconnaissance only)
- **Virtualization:** VMware Workstation

## Project Objectives
- Perform passive footprinting and reconnaissance.
- Identify open ports and running services.
- Enumerate exposed services and potential misconfigurations.
- Assess vulnerabilities and associated risks.
- Demonstrate exploitation of three distinct vulnerabilities within the authorized lab.
- Document findings, impacts, and remediation recommendations.

## Tasks Completed
- Task 01: Footprinting & Reconnaissance
- Task 02: Network Scanning
- Task 03: Service Enumeration
- Task 04: Vulnerability Assessment
- Task 05: Exploitation
- Task 06: Professional VAPT Report
- Task 07: Portfolio Documentation

## Disclaimer
All exploitation activities were performed within an isolated and authorized lab environment using Metasploitable 2. Public-domain reconnaissance was limited to permitted information gathering. No unauthorized exploitation of public systems was conducted.
